                        Weekend project
                        
nlsearch

                        

                            Docs
                            Source
                            Write-up
                        

                    

                    
An Elasticsearch plugin that adds a _nl endpoint. You send a sentence, an LLM plans
                        the matching Elasticsearch call, the plugin runs it and returns a short answer with the raw
                        result. It reads the index mappings first so the model uses real field names, retries once if
                        Elasticsearch rejects the plan, and keeps session history for follow-up questions.
